Desarrollo web: HTML, CSS y animación

Desarrollo web · Inicio

Tu sitio en la red

En esta unidad vas a construir tu propia página web sobre un tema que te guste (tu deporte, tu grupo de música, tus videojuegos, tu pueblo, una afición…), como lo harías para un club, un pequeño negocio o un canal. La harás con los mismos lenguajes con los que están hechas todas las páginas que visitas a diario, y aprenderás a darle estructura, contenido, estilo, movimiento y a usar imágenes de forma legal.

¿Qué vas a conseguir?

Al terminar tendrás una página web personal hecha por ti, con:

  • Una estructura correcta en HTML (títulos, párrafos, listas, enlaces, tablas).
  • Al menos una imagen con licencia libre, correctamente atribuida.
  • Un estilo propio con CSS (colores, fuentes, disposición).
  • Al menos una animación web (transición o animación CSS).

La entregarás en Google Classroom y la enseñarás en una presentación breve a la clase.

¿Con qué herramienta vamos a trabajar?

Para escribir el código de tu página tienes dos opciones. Las dos son gratuitas, funcionan en el navegador del aula y no necesitan instalar nada ni crear cuenta.

Opción A · Editor online (recomendada; sirve también en casa)

Usaremos HTML Code Runner, un editor de páginas web que funciona dentro del navegador, sin cuenta y sin instalar nada.

Entra aquí: htmlcoderunner.com/es

Cómo se usa (3 pasos):

  1. Escribe tu código HTML (y el CSS) en el recuadro de la izquierda.
  2. Pulsa «Ejecutar» (Run) para ver el resultado al instante a la derecha.
  3. Cuando termines, pulsa «Descargar» (Download): se guardará un archivo .html en tu carpeta de descargas. Ese es el archivo que subirás a Google Classroom.

Consejo: el editor no guarda tu trabajo solo. Descarga tu archivo antes de cerrar la pestaña.

Opción B · Editor «Pluma» del aula

En los ordenadores del aula tienes el editor de texto Pluma. Escribe el código, usa Archivo → Guardar y ponle un nombre que termine en .html. Después haz doble clic en el archivo para abrirlo en el navegador. Cada vez que cambies el código, guarda y pulsa F5 en el navegador para actualizar.

Cómo entregar tu trabajo

Todo se entrega en Google Classroom

Todas las tareas de esta unidad se entregan en Google Classroom, en la tarea que corresponda. Salvo que se diga otra cosa, subirás el archivo .html que hayas creado (o el que te descargues del editor online).

Cómo nombrar tus archivos (¡muy importante!)

Para no perder ni mezclar ningún trabajo, en cada sesión guardas tu archivo con un nombre fijo: el mismo para toda la clase. No pongas tu nombre ni tus apellidos en el nombre del archivo; Google Classroom ya sabe que la entrega es tuya. Escribe el nombre tal cual, en minúsculas, sin espacios y sin tildes ni ñ.
