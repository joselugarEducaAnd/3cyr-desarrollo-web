Desarrollo web: HTML, CSS y animación

S7 · Animación web

¡Que se mueva!

Una animación hace tu página más viva y llamativa. Hay varias formas de conseguir movimiento en la web; vamos a ver los formatos y las herramientas, y luego harás tu propia animación con CSS. Tu web final debe llevar al menos una animación.

Formatos de animación en la web

FormatoQué esCómo se pone
GIF animadoUna imagen que se mueve sola en bucle (como los memes). Pesa bastante.Con <img>, igual que una foto.
SVG animadoUn dibujo hecho con código (líneas, formas) que puede moverse. Se ve nítido a cualquier tamaño.Con <img> o pegando el código SVG.
VídeoUn vídeo incrustado en la página, con controles de reproducción.Con <video>.
Transición CSSUn cambio suave al pasar el ratón. La más fácil y la que vas a usar.Con transition y :hover.
Animación CSSUn movimiento que se repite solo, sin tocar nada.Con @keyframes y animation.

Incrustar un vídeo (cópialo)

<video src="mi_video.mp4" controls width="400"></video>

controls muestra los botones de reproducir/pausa.

Herramientas útiles (web, sin instalar ni cuenta)

  • ezgif.com → crear y recortar GIF animados en el navegador.
  • giphy.com → banco de GIF (revisa siempre que puedas reutilizarlo).
  • Openverse → también encuentra GIF y SVG con licencia libre.

Recuerda las licencias

Un GIF o un vídeo también tienen dueño. Si lo descargas de internet, que sea de un banco libre y atribúyelo, igual que hiciste con las imágenes en la S4.

Mínimo común: una transición al pasar el ratón

Con dos líneas de CSS puedes hacer que algo cambie suavemente cuando el ratón pasa por encima. La palabra clave :hover significa «cuando el ratón está encima».

Un título que crece y cambia de color (cópialo)

<style>
  h1 {
    color: #453f93;
    transition: all 0.4s;   /* el cambio dura 0,4 segundos */
  }
  h1:hover {
    color: orange;
    font-size: 45px;        /* al pasar el ratón, se agranda */
  }
</style>

Pon el ratón encima del <h1> y verás cómo cambia poco a poco. La clave es transition: sin ella, el cambio sería brusco.

Extensión: una animación que se mueve sola

Con @keyframes defines un movimiento y con animation se lo aplicas a un elemento. Se repite solo, sin tocar nada.

Un título que «late» (cópialo)

<style>
  @keyframes latido {
    0%   { transform: scale(1);   }
    50%  { transform: scale(1.2); }  /* a la mitad, más grande */
    100% { transform: scale(1);   }
  }
  h1 {
    animation: latido 1.5s infinite;  /* se repite sin parar */
  }
</style>

Otra idea: un elemento que se desliza al entrar (cópialo)

<style>
  @keyframes entra {
    from { transform: translateX(-100px); opacity: 0; }
    to   { transform: translateX(0);      opacity: 1; }
  }
  .tarjeta { animation: entra 1s; }
</style>

Consejo de buen gusto

Una animación llama la atención… si no hay veinte a la vez. Con una o dos bien elegidas tu página gana mucho; si son demasiadas, marea.
