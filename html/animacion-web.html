Desarrollo web: HTML, CSS y animación

Animación web

¡Que se mueva!

Una animación hace tu página más viva y llamativa. Hay varias formas de conseguir movimiento en la web; vamos a ver los formatos y las herramientas, y luego harás tu propia animación con CSS. Tu web final debe llevar al menos una animación.

Formatos de animación en la web

FormatoQué esCómo se pone
GIF animadoUna imagen que se mueve sola en bucle (como los memes). Pesa bastante.Con <img>, igual que una foto.
SVG animadoUn dibujo hecho con código (líneas, formas) que puede moverse. Se ve nítido a cualquier tamaño.Con <img> o pegando el código SVG.
VídeoUn vídeo incrustado en la página, con controles de reproducción.Con <video>.
Transición CSSUn cambio suave al pasar el ratón. La más fácil y la que vas a usar.Con transition y :hover.
Animación CSSUn movimiento que se repite solo, sin tocar nada.Con @keyframes y animation.

Herramientas útiles (web, sin instalar ni cuenta)

  • Openverse → GIF y SVG con licencia libre. Es el banco que debes usar para tu página.
  • ezgif.com → crear y recortar GIF animados en el navegador, por ejemplo a partir de tus propias fotos.
  • giphy.com → solo para inspirarte: sus GIF no traen una licencia que te deje usarlos en tu página.

¿Dónde escribo el CSS de la animación?

  • Si en la S6 pasaste tu CSS a estilos.css: abre estilos.css con Pluma y pega el código al final, tal cual lo ves en los ejemplos de abajo. Guarda, abre tu página con doble clic y pulsa F5.
  • Si tu CSS sigue en la página: pégalo dentro de tu <style>, antes de </style>.

En estilos.css nunca van las etiquetas <style> ni </style>: si las pegas, el navegador se salta la primera regla sin avisar. Y recuerda que el editor online no ve tu estilos.css: hoy trabaja con Pluma + F5.

Mínimo común: una transición al pasar el ratón

Con dos reglas de CSS puedes hacer que algo cambie suavemente cuando el ratón pasa por encima. La palabra clave :hover significa «cuando el ratón está encima».

Un título que crece y cambia de color (cópialo en dos sitios)

1. En tu página, ponle la clase efecto a lo que quieras animar:

<h1 class="efecto">Mi equipo de baloncesto</h1>

2. En tu CSS:

.efecto {
  transition: all 0.4s;   /* el cambio dura 0,4 segundos */
}
.efecto:hover {
  color: orange;
  font-size: 45px;        /* al pasar el ratón, se agranda */
}

Pon el ratón encima y verás cómo cambia poco a poco. La clave es transition: sin ella, el cambio sería brusco. Cambia orange y 45px por los valores que te gusten.

¿No cambia de color? Si ese elemento ya tiene un id con color (por ejemplo #portada), el id manda. Escribe la regla con el id: #portada:hover { … }.

EscribesSignifica

translateX(-100px)100 píxeles a la izquierda

Extensión: una animación que se mueve sola

Con @keyframes defines un movimiento y con animation se lo aplicas a un elemento. Se repite solo, sin tocar nada.

Algo que «late» (cópialo en tu CSS)

@keyframes latido {
  0%   { transform: scale(1);   }
  50%  { transform: scale(1.1); }  /* a la mitad, más grande */
  100% { transform: scale(1);   }
}
.efecto {
  display: inline-block;            /* para que el efecto funcione */
  animation: latido 1.5s infinite;  /* se repite sin parar */
}

Queda mejor en una imagen o en un título corto. No funciona en un enlace, un <strong> o un <em> si no le pones display: inline-block.

Otra idea: algo que se desliza al entrar (cópialo en tu CSS)

@keyframes entra {
  from { transform: translateX(-100px); opacity: 0; }
  to   { transform: translateX(0);      opacity: 1; }
}
.tarjeta { animation: entra 1s; }

Ponle class="tarjeta" al elemento que quieras que entre. Sin esa clase en tu página, no pasa nada.

Pruébalo tú: laboratorio de animación

Cambia la duración y el efecto, y mira cómo cambia el código. Cuando te guste el resultado, puedes copiarlo a tu página.

Prueba a poner la transición a 0 segundos: así se ve una página a la que le falta transition.

El código del laboratorio va dentro de tu <style> o en estilos.css, nunca suelto en la página. Usa la clase efecto: ponle class="efecto" a lo que quieras animar.

Consejo de buen gusto

Con una o dos animaciones bien elegidas tu página gana mucho; con veinte, marea.

Al final de esta clase: cuestionario

Cuando subas s7.html y estilos.css, harás un cuestionario en Google Forms (unos 20 minutos, sin libro ni apuntes) sobre todo lo visto en la unidad: cómo funciona la web (navegador, servidor, tipos de servidor y partes de una URL), la estructura de una página, los formatos y herramientas de animación de esta página y cómo encontrar fallos típicos en tu código.
