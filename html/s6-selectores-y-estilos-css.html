S6 · Selectores y estilos CSS

Apuntar al elemento justo

Hasta ahora has dado estilo a etiquetas enteras (todos los <h1>, todos los <p>). Con los selectores puedes ser más preciso: aplicar un estilo a un elemento concreto o a un grupo que tú elijas.

Los tres selectores básicos

SelectorA qué se aplicaEn CSS se escribe
De etiquetaA todas las etiquetas de ese tipo.p { ... }
De claseA las etiquetas que tengan ese class. Puede repetirse..destacado { ... }
De identificadorA un único elemento con ese id.#cabecera { ... }

Clases e identificadores (cópialo)

<!-- HTML -->
<p class="destacado">Este párrafo es especial.</p>
<p id="cabecera">Solo hay uno como este.</p>

<!-- CSS -->
.destacado { color: orange; font-weight: bold; }
#cabecera  { background-color: #453f93; color: white; }

La clase se marca con un punto (.) y puede estar en muchas etiquetas. El id se marca con almohadilla (#) y debe ser único en la página.

Combinar selectores

h1, h2, .destacado { color: green; }  /* a varios a la vez, separados por comas */
p.aviso { text-decoration: underline; } /* solo los párrafos con class="aviso" */

El modelo de caja

Cada elemento es una caja. Puedes controlar el espacio de dentro (padding), el borde (border) y el espacio de fuera (margin).

.tarjeta {
  border: 2px solid #453f93;
  padding: 12px;     /* espacio interior */
  margin: 20px;      /* espacio exterior */
}

Pruébalo tú: el modelo de caja

Mueve los deslizadores y fíjate en dos cosas: qué zona crece en la caja y cómo cambia el ancho total que ocupa en la página.

El padding y el border hacen la caja más grande aunque el contenido mida lo mismo; el margin solo la separa de lo que tiene alrededor.

Una hoja de estilos externa

Lo más profesional es escribir el CSS en un archivo aparte (por ejemplo estilos.css) y enlazarlo. Así un mismo estilo sirve para muchas páginas.

Enlazar estilos.css (cópialo en el <head>)

<link rel="stylesheet" href="estilos.css">

En estilos.css va solo CSS (sin etiquetas HTML ni <style>).

Tarea S6 · Selectores y hoja externa

Parte de tu s5.html y trabaja con selectores:

  1. Crea una clase (por ejemplo destacado) y aplícala a algún elemento.
  2. Da estilo a un elemento único con un id.
  3. Usa margin, padding o border en algún bloque.
  4. Mueve tu CSS a un archivo aparte llamado estilos.css y enlázalo con <link>.

Guarda la página como s6.html y súbela junto con estilos.css a Google Classroom.

Nombres de los archivos: s6.html y estilos.css

Ampliación (opcional)

Investiga el selector p.clase (etiqueta + clase) y crea una regla que solo afecte a los párrafos con una clase concreta.

Clasifica
