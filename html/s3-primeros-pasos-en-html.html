S3 · Primeros pasos en HTML

Tu primera página HTML

HTML está formado por etiquetas que el navegador interpreta. Una etiqueta se escribe entre < y >. La mayoría van por pares: una de apertura y otra de cierre (con una barra /), y entre las dos va el contenido.

La anatomía de un elemento

<p>Esto es un párrafo.</p>
  • <p> → etiqueta de apertura (empieza el párrafo).
  • Esto es un párrafo. → el contenido.
  • </p> → etiqueta de cierre (termina el párrafo).

Algunas etiquetas están vacías y no se cierran, como <br> (salto de línea) o <img> (imagen).

La estructura mínima de una página

Toda página HTML tiene siempre el mismo esqueleto. Cópialo: es tu punto de partida.

Esqueleto básico (cópialo y pruébalo)

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="utf-8">
    <title>Mi primera página</title>
  </head>
  <body>
    <h1>¡Hola, mundo!</h1>
    <p>Esta es mi primera página web.</p>
  </body>
</html>
ElementoPara qué sirve
<!DOCTYPE html>Avisa de que es una página HTML moderna. Va siempre la primera.
<html>Envuelve toda la página.
<head>Información que no se ve: título de la pestaña, juego de caracteres…
<meta charset="utf-8">Permite mostrar tildes y ñ correctamente.
<title>El texto que aparece en la pestaña del navegador.
<body>Todo lo que sí se ve en la página.

Encabezados y párrafos

Dentro del <body> organizas el texto con encabezados (<h1> a <h6>, del más importante al menos) y párrafos (<p>).

<h1>Título principal</h1>
<h2>Un apartado</h2>
<p>Un párrafo con la explicación del apartado.</p>
<hr>
<p>Otro párrafo después de una línea de separación.</p>

<hr> dibuja una línea horizontal de separación y <br> hace un salto de línea. Ninguno se cierra.

Tarea S3 · Mi primera página

Crea una página HTML sobre tu tema partiendo del esqueleto básico. Debe tener:

  1. Un <title> con sentido (aparecerá en la pestaña).
  2. Un <h1> con el título de tu página y algún <h2>.
  3. Al menos dos párrafos que presenten tu tema.
  4. Una línea de separación <hr>.

Esta página es la base de tu web final: la irás ampliando en las próximas sesiones. Guárdala con el nombre s3.html y súbela a Google Classroom.

Nombre del archivo: s3.html

Ampliación (opcional)

Añade dentro del texto una palabra en negrita con <strong> y otra en cursiva con <em>.
