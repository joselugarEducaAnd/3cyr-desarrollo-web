Desarrollo web: HTML, CSS y animación

Chuleta de HTML y CSS

Todo a mano

Esta página es tu chuleta: las etiquetas y propiedades que más vas a usar, juntas. Vuelve aquí siempre que se te olvide algo.

Etiquetas HTML esenciales

EtiquetaPara qué
<h1>…<h6>Encabezados (del más al menos importante).
<p>Párrafo.
<br> · <hr>Salto de línea · línea de separación.
<strong> · <em>Negrita · cursiva.
<ul> <ol> <li>Listas (con viñetas / numeradas) y sus elementos.
<a href="...">Enlace (añade target="_blank" rel="noopener").
<img src="..." alt="...">Imagen (no se cierra).
<table> <tr> <th> <td>Tabla, fila, celda de cabecera, celda.
<!-- ... -->Comentario (no se ve).

Propiedades CSS esenciales

PropiedadQué cambia
colorColor del texto.
background-colorColor de fondo.
font-family · font-sizeTipo y tamaño de letra.
text-alignAlineación (left, center…).
margin · padding · borderEspacio exterior · interior · borde.
transitionCambio suave (con :hover).
@keyframes · animationAnimación que se repite sola.

Selectores CSS

SelectorAplica a…
p { }Todas las etiquetas de ese tipo.
.clase { }Las etiquetas con ese class.
#id { }El único elemento con ese id.
h1, h2 { }Varios a la vez (separados por comas).

Regla de oro

El navegador ignora lo que no entiende y sigue. Si algo no se ve como quieres, revisa que las etiquetas estén bien cerradas y los ; del CSS en su sitio.
