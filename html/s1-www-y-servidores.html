S1 · WWW y servidores

¿Qué pasa cuando escribes una dirección?

Cuando escribes una dirección como www.wikipedia.org y pulsas Intro, ocurre algo parecido a pedir un libro en una biblioteca enorme: tu ordenador pide la página y otro ordenador, muy lejos, se la envía. Todas esas páginas forman la World Wide Web (WWW): la telaraña mundial de documentos enlazados entre sí a la que accedes con un navegador.

Los dos protagonistas: navegador y servidor

Para que veas una página web hacen falta dos ordenadores trabajando juntos:

  • El navegador (Firefox, Chrome…) es el programa de tu ordenador. Pide las páginas y las muestra en pantalla.
  • El servidor web es un ordenador especial que está encendido siempre y guarda las páginas. Cuando el navegador se las pide, se las manda.

Esas reglas para pedir y enviar páginas se llaman HTTP (o HTTPS, la versión segura). Por eso las direcciones empiezan por https://.

¿Por qué un servidor y no un ordenador cualquiera?

Porque a una página famosa la visitan miles de personas a la vez. Un servidor está preparado para estar encendido las 24 horas y atender muchísimas peticiones sin bloquearse. Las webs con mucho tráfico se copian en varios servidores que se reparten el trabajo.

No solo hay servidores web

Un servidor es cualquier ordenador que ofrece un servicio a otros. Según lo que ofrezcan, hay varios tipos:

Tipo de servidorPara qué sirve
Servidor webGuarda y envía páginas web.
Servidor de correoGestiona el envío y la recepción de correos.
Servidor de archivosAlmacena archivos para compartirlos.
Servidor de bases de datosGuarda datos organizados para las aplicaciones.

Las partes de una dirección (URL)

Mira una página por dentro

Todas las páginas están escritas con un lenguaje llamado HTML (lo aprenderás a partir de la próxima sesión). Puedes verlo tú mismo:

Inspeccionar una página real

  1. Abre en el navegador una página que te guste (por ejemplo, la Wikipedia).
  2. Haz clic derecho sobre cualquier parte de la página.
  3. Elige «Inspeccionar» (o pulsa la tecla F12).
  4. Se abrirá un panel con el código HTML de la página. Pasa el ratón por encima de las líneas y verás cómo se iluminan las partes de la página.
