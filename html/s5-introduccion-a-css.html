S5 · Introducción a CSS

Ahora, el estilo

Tu página ya tiene contenido, pero se ve sosa. CSS (Hojas de Estilo en Cascada) sirve para decidir su aspecto: colores, tipos de letra, tamaños, fondos, alineación… La idea es separar el contenido (HTML) de la presentación (CSS).

Tres formas de añadir CSS

FormaCómoCuándo
En una etiquetaAtributo style dentro de la etiqueta.Para un retoque puntual.
En la páginaEtiqueta <style> dentro del <head>.Para dar estilo a toda una página. Es la que usaremos hoy.
En un archivo aparteArchivo .css enlazado.Para todo un sitio de varias páginas (lo verás en la S6).

La sintaxis de CSS

Una regla CSS tiene un selector (a qué se aplica) y, entre llaves, una o varias propiedades con su valor:

h1 {
  color: #453f93;          /* color del texto */
  text-align: center;      /* centrado */
}

Cada propiedad termina en punto y coma ;. Lo que va entre /* ... */ es un comentario y no afecta.

Poner CSS en tu página

Estilo para toda la página (cópialo dentro del <head>)

<style>
  body {
    background-color: #f4f2fb;   /* color de fondo */
    font-family: Arial, sans-serif;
    color: #24262e;
  }
  h1 {
    color: #453f93;
    text-align: center;
  }
</style>

Propiedades básicas para empezar

PropiedadQué cambiaEjemplo de valor
colorColor del texto.red, #453f93
background-colorColor de fondo.#f4f2fb
font-familyTipo de letra.Arial, sans-serif
font-sizeTamaño de la letra.20px
text-alignAlineación del texto.center, left

Sobre los colores

Un color puede escribirse con su nombre en inglés (red, blue, orange) o con su código hexadecimal #RRGGBB (por ejemplo, el morado del instituto es #453f93).

Tarea S5 · Da estilo a tu página

Abre tu s4.html y añade una etiqueta <style> dentro del <head> para conseguir, al menos:

  1. Un color de fondo para la página (body).
  2. Un tipo de letra para toda la página.
  3. Un color propio para los títulos y otro para los párrafos.
  4. Los títulos centrados.
