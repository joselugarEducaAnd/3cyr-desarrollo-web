Desarrollo web: HTML, CSS y animación

S2 · Estructura y herramientas

Antes de programar, mira cómo están hechas

Casi todas las páginas web comparten una misma estructura y se construyen con unas herramientas y unos lenguajes parecidos. Conocerlos te ayudará a diseñar la tuya con criterio.

Las tres partes de una página

  • Cabecera (header): la parte de arriba. Suele llevar el logo, el menú de navegación y un buscador. Es igual en todas las páginas del sitio.
  • Cuerpo (body): el contenido principal. Es diferente en cada página (no es lo mismo la portada que la página de contacto).
  • Pie (footer): la parte de abajo. Suele llevar información de contacto, redes sociales y enlaces legales. También se repite.

Herramientas del desarrollo web

Un desarrollador combina texto, colores, fotos, iconos y vídeos. Para ello usa herramientas de varios tipos:

HerramientaPara qué sirve
Banco de imágenesDescargar fotos (algunas gratis, otras de pago).
Banco de iconosIconos clasificados por temas y estilos.
Editor de paleta de coloresElegir combinaciones de colores que peguen entre sí.
Repositorio de tipografíasElegir tipos de letra.
Editor de imágenesRecortar, girar o retocar fotos.
Maquetador visual / plantillasMontar la web arrastrando bloques (Wix, Google Sites…).

Lenguajes para hacer páginas web

Los maquetadores por bloques son cómodos, pero hacen páginas parecidas entre sí. Para crear una web a medida se usan lenguajes de edición:

  • HTML (HyperText Markup Language): el más sencillo y básico. Da el contenido y la estructura mediante etiquetas. Es el que aprenderás.
  • HTML5: la versión actual de HTML, recomendada por ser más accesible.
  • CSS (Cascading Style Sheets): define el estilo o aspecto (colores, tamaños, disposición). Lo verás a partir de la S5.
  • XML / XHTML: otros lenguajes de marcas relacionados, más usados para intercambiar datos.

La idea clave

HTML pone el contenido y la estructura; CSS pone el estilo. Separar las dos cosas hace las páginas más fáciles de mantener.

Tarea S2 · Analiza una web

En esta sesión no creas ningún archivo. Responde en el documento de la tarea de Google Classroom:

  1. Elige una web que uses. Identifica su cabecera, su cuerpo y su pie, y di qué hay en cada uno (haz una captura y señálalos).
  2. Rellena una tabla con una herramienta de cada tipo de la lista de arriba, con su enlace.
  3. Explica con tus palabras la diferencia entre HTML y CSS.
